# Workflow

## Phase 1 — Export

The script scans the selected folder's direct children and creates an Excel control file.

## Phase 2 — Configure

The user enters desired names in the `New Name` column.

## Phase 3 — Validate

The script checks naming rules, source existence, duplicate targets, target collisions, and file/folder consistency.

## Phase 4 — Confirm

The user receives a validation summary and must explicitly confirm the operation.

## Phase 5 — Execute

Valid rename operations are executed without overwriting existing targets.

## Phase 6 — Audit

An Excel log and summary are generated after the operation.
